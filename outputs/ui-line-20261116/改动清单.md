## 1. 设计语言

只用三种几何母题：

| 母题 | 用法 | 规则 |
| --- | --- | --- |
| 线 | 1px 发丝描边承担层级 | 卡片/输入框/分隔线只描边，不用大面积色块；阴影只作"贴地" |
| 点 | 6px 圆点 / 32px 方形字形块 | 类型、分类、标签统一用圆点 + 文字，不再用彩色胶囊 |
| 切角 | 卡片右上角 14px L 形直角 | 悬停/聚焦时由 0 → 1 出现，作为唯一的"可点"装饰 |

块面构成：
- 一屏最多一个主强调色块（主按钮 / 当前分段）；
- 统计块靠右上角几何图形（方块 / 圆 / 横线）区分，不靠三种底色；
- 页面画布是 48px、4% 透明度的几何网格，只在内容内边距里露出。

### 2.2 字号（`--fs-*` / `TYPE_SCALE`）

| 档位 | 值 | 用途 |
| --- | --- | --- |
| `hero` | 30px | 首页/品牌大标题 |
| `display` | 24px | 页面主标题 |
| `title` | 16px | 卡片标题/分区标题 |
| `body` | 14px | 正文 |
| `meta` | 13px | 辅助说明 |
| `caption` | 11.5px | 标签/时间/计数 |

字距：`--tracking-label: .14em`（全大写小标签）、`--tracking-tight: -.01em`（标题）。
行高：`--lh-tight: 1.25`、`--lh-body: 1.6`。

### 2.3 间距（4pt 节奏，`--s-*` / `SPACE`）

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`

页面内边距只用 `12 / 16 / 24 / 32 / 48`；卡片内边距统一 16；列表行间距 8。

| --- | --- | --- |

### 2.5 动效

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--motion-press` | 90ms | 按压缩放（只做 transform） |
| `--motion-fast` | 120ms | 描边/底色悬停 |
| `--motion-enter` | 200ms（流畅方案 220ms） | 页面/卡片进场 |
| `--motion-exit` | 140ms | 退场/变淡 |
| `--motion-move` | 240ms（流畅方案 260ms） | 位移/抬起 |
| `--motion-stagger` | 26ms | 列表错峰（尾部封顶第 8 项） |
| `--motion-ease-enter` | `cubic-bezier(.16,1,.3,1)` | 进场 |
| `--motion-ease-exit` | `cubic-bezier(.4,0,1,1)` | 退场 |
| `--motion-ease-standard` | `cubic-bezier(.4,0,.2,1)` | 通用 |
| `--motion-ease-spring` | `cubic-bezier(.2,.9,.2,1)` | 卡片落位 |

保留既有方案差异：`data-scheme='zoned'` 只改布局（1120px / 20px 栅格），`data-scheme='fluid'` 只改动效（220/140/260ms、10px 位移）。
系统开启「减弱动效」时，所有时长为 0、位移取消，骨架屏停止闪动。
