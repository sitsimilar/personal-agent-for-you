# 背景主题（第二层画布）说明

> 日期：2026-11-16　范围：`web/src` 呈现层 + `qa/` 截图脚本
> 结论先说：**推荐默认用「轨道线」（orbit）**，夜间深色可换「星野」，喜欢纸张地图气质可换「等高线」。三套都能一键关掉，每套都能在设置页调四个参数（速度 / 强度 / 模糊 / 透明度）。

## 1. 怎么切、看哪几页

| 入口 | 路径 | 说明 |
|---|---|---|
| 顶栏快捷入口 | 任意页 → 顶栏调色板图标 → 弹层底部「背景氛围」 | 四个胶囊：关闭 / 轨道线 / 星野 / 等高线。点选即时生效，底部提示 6 秒内可「撤销」（只切主题，不带参数） |
| 设置页卡片 | `/settings` → 「背景氛围」卡片（`#ui-backdrop`） | 四张预览图 + **四个参数滑杆** + 取值范围与安全上限 + 当前档位的「气质 / 性能 / 适合 / 实现」 |

**建议对比的页面**

1. `/`（首页）——留白最多、卡片密度适中，最容易看出三套的差异；
2. `/records`（记录列表）——窄屏会自动切紧凑单行，用来看装饰层是否干扰扫描；
3. `/todo`（待办）——行高更密，用来看「背景是否影响勾选与输入」；
4. `/settings#ui-backdrop`——四套的取舍说明都在这里。

窄屏（<768px）背景会自动缩小并右移出画布，避免与正文抢视线。

## 2. 三套候选 + 关闭

### 2.1 关闭（off）

- **气质**：安静、纸张感，只剩 48px 几何网格。
- **性能**：零。`off` 时**渲染层根本不挂载**（不是 `display:none`）。
- **适合**：长时间阅读、低电量、录屏与截图。
- **取舍**：最安全，但也就没有「升级了」的第一眼感知。

### 2.2 轨道线（orbit，默认）

- **是什么**：同心圆 + 两个沿轨道缓慢公转的点 + 十字定位线 + 几枚方形节点。
- **气质**：秩序、仪器感，最贴近现有「线构」（线 / 点 / 方形块 / 切角）。
- **性能**：无 Canvas、无 `requestAnimationFrame`，只有两个 `transform: rotate` 关键帧（140s / 86s），交给合成层，估算 <1% CPU。
- **适合**：日常默认；想有点生气但不抢注意力。
- **取舍**：动效最弱，几乎是「静态构图 + 极慢公转」；喜欢的会觉得克制，想要星空感的会觉得不够。

### 2.3 星野（starfield）

- **是什么**：Canvas 2D 星点 + 近邻星座线，明暗呼吸周期 8–20s，无位移漂移。
- **气质**：深空、克制，深色下最成立。
- **性能**：30fps 上限（33ms 节流）、DPR 上限 1.5、连线对在初始化时**一次算好**、`visibilitychange` 隐藏即暂停、减弱动效只画一帧。估算桌面 2–4% CPU。
- **适合**：夜间 / 深色模式写作与整理。
- **取舍**：唯一需要帧循环的一套。浅色下星点必须压得很淡（否则像脏点），所以白天存在感明显低于深色。

### 2.4 等高线（terrain）

- **是什么**：3 段 2D value noise 叠出的横向等高线，每 6 条挑一条用品牌色。
- **气质**：山野、地理，像一张摊开的地形图。
- **性能**：**只画一次**；之后的缓慢横移由 CSS `transform` 完成（150s 一个来回，幅度 1.6%），每帧脚本开销为 0。
- **适合**：白天 / 浅色模式，喜欢纸张地图阅读氛围。
- **取舍**：静态图 + 合成层平移，意味着它不能「实时演化」；缩放窗口会重画一次（可接受）。

## 3. 参数面板（设置页，本次新增）

**怎么进**：登录 → `/settings` → 第二张卡「背景氛围」（`id="ui-backdrop"`）。顶栏只切主题，参数集中在这一张卡里，避免两处维护。

**怎么调**：先点一套主题（点选即时生效、不刷新），再拖四个滑杆。滑杆右侧是当前值（等宽数字），下方三个刻度分别是「最小 / 中位 / 最大」，改过的项在标签右侧出现一个 4px 品牌色圆点；右上「恢复默认」只重置**当前主题**。

### 3.1 四个参数（命名 / 范围 / 默认值）

| 参数 | 范围 | 步进 | 刻度 | 改的是什么 | 为什么卡在这个范围（安全上限） |
|---|---|---|---|---|---|
| 变化速度 | 0–100 | 1 | 静止 / 慢 / 快 | 动画走多快；0 是**真停帧**（`animation-play-state: paused`，Canvas 不进 rAF） | 上限 100 ≈ 轨道 45s/圈、等高线 50s 单程、星野呼吸 2 倍速。再快接近闪烁（前庭不适），且星野本身封顶 30fps，再快也没有额外帧 |
| 线条强度 | 0–100 | 1 | 极淡 / 中等 / 上限 | 同时调线宽（0.6–1.6px）与颜色 alpha | 100% 就是**对比度预算的上限**：线 alpha ≤10%、点 alpha ≤30%（浅）/ 62%（深）。再往上会和卡片的 1px 发丝描边打架，容易被当成分割线 |
| 模糊度 | 0–4px | 0.5 | 实线 / 2px / 化雾 | 只给装饰层加 `filter: blur()`，不碰正文 | 4px 已把 1px 发丝线摊成薄雾（峰值 alpha 只剩约 1/5）；再高只是加全屏离屏采样成本，低端集显掉帧 |
| 透明度 | 0–100 | 1 | 0 / 50 / 100 | 整层 `opacity` | 0–100 都安全：100% 的浓度上限已由「强度」锁死。0 只用于对照，真要省电请选「关闭」（渲染层不挂载） |

**模糊的替代做法（重要）**：模糊无法**独立**实现成一个像样的观感——`filter: blur(r)` 会把 1px 线摊到 `1+2r` 像素上，峰值 alpha 近似按 `1/(1+2r)` 衰减，4px 时背景看起来就像被关掉了。所以这里做了**线宽补偿**：模糊 >1px 时线宽乘 `1 + (模糊-1)/3 × 2.2`（最多约 ×3.2），**只加宽、不加 alpha**，总墨量守恒，对比度预算不变，形体仍然看得见。这也是为什么 `params__*__max`（模糊拉满）看起来是「一层雾」而不是「线条消失」——刻意行为，不是参数失效。想看清线条本身的效果请看 `params__*__maxline`（模糊 0、其余拉满）与 `blur__*` 三档对照。

### 3.2 每套主题的推荐默认值

| 主题 | 速度 | 强度 | 模糊 | 透明度 | 为什么是这组值 |
|---|---|---|---|---|---|
| 关闭 off | 0 | 90% | 0px | 80% | 不使用；保留数值，切回来不丢用户手感 |
| 轨道线 orbit | 50 | 92% | 0px | 92% | 发丝线要「锐」才有仪器感；50 速度＝约 147s/圈，几乎察觉不到在动 |
| 星野 starfield | 50 | 92% | 0px | 94% | 星点必须锐，模糊会直接化成灰雾；深色下已把点 alpha 提到 62% 保证不过淡 |
| 等高线 terrain | 50 | 90% | 1px | 90% | 1px 是「手绘纸感」的临界点，再糊就只剩色块 |

**切换规则**：切主题时套用该主题的推荐值；**用户手动改过的值按主题分别记住**（`backdropParams[theme]`），切走再切回来还是你的手感。「恢复默认」只作用于当前主题。主题与全部参数一起写 `localStorage`（`pa.ui.backdrop`，v2），重开还在；**不写账号、不动数据库**。

### 3.3 窄屏与可读性

- 主题块 `xs` 单列、`≥sm` 两列；滑杆 `xs` 单列全宽、`≥md` 两列，每根滑杆之间留 26px 给刻度文字，390px 下不会叠字；
- 参数面板与「取值说明」用 `minmax(0,1fr)`，长文案换行不撑破卡片；
- 背景层始终 `pointer-events: none` + `aria-hidden`，卡片是不透明 `--surface`，正文全在实体卡片上；
- `prefers-reduced-motion: reduce`：CSS 停掉轨道与地形平移，星野只画一帧、不进 rAF；参数改值仍然生效（静态重绘），面板顶部显示「系统已开启减弱动效」提示。

## 6. 硬约束逐条落实

| 约束 | 落法 | 证据 |
|---|---|---|
| 首屏不被阻塞 | 装饰层在登录后的 `Layout` 里挂载，`useEffect` 内起帧（首帧渲染之后）；Canvas 尺寸在 rAF 里设置，不做同步重活 | 探针：`errors: []`，无页面异常；`layerZ=0`、`mainZ=1` |
| 正文对比度 | 卡片是**不透明** `--surface`，装饰只在留白处；装饰线 alpha ≤ 10%（深色）/ 10%（浅色），星点用 `--bd-dot` | 截图可见正文全在实体卡片上；三套描述已写入设置页 |
| 不影响输入/点击 | 整层 `pointer-events: none` + `aria-hidden`，`z-index: 0` 在内容之下 | 探针：`layerPointerEvents: "none"`（全部 16 组） |
| `prefers-reduced-motion` 自动静态 | CSS 停掉 `.bd-track` / `.bd-canvas-terrain` 动画；JS 侧星野只画一帧、不启动 rAF | reducedMotion 上下文：`trackAnimation: "none"`，无 Canvas 帧循环 |
| 一键关闭 | 设置页「关闭」+ 顶栏胶囊「关闭」，都即时生效、可撤销；`off` 时不挂载渲染层 | 探针：`backdrop=off` 时 `layer: false`、`canvas: false` |
| 参数拖到极端不卡顿 / 不糊正文 | 四个滑杆的 min–max 本身就是安全区间，越界值由 `clampBackdropParam` 夹回；强度上限＝alpha 预算；速度 0 是真停帧；模糊 4px 封顶并做线宽补偿 | 极值截图 `params__*__max / min`、`blur__*`；验收里 `localStorage` 存的就是夹好的值 |
| 参数与主题一起持久化 | `localStorage` `pa.ui.backdrop` v2 存 `{theme, params[theme]}`，`hydrateLocal` 在首帧前落地；兼容 v1 旧值 | 刷新后 `--bd-layer-opacity` 仍为 `1.00`，滑杆标签仍显示 100% |
| 不引大体量依赖 | 无 WebGL、无粒子引擎、无噪声库；Canvas 全部手写 | 依赖与 lockfile 未改 |
| 不动业务/服务/后端/数据库 | 只改呈现层与本地偏好存储，背景**不写云端**、不加 `settings` 列 | `uiSchemeStore` 里 `setBackdrop` 只写 localStorage |
| 中文文案沿用现有风格 | 卡片、胶囊、提示语沿用「静默化 / 分区骨架 / 流畅优先」的短句 + 一句解释结构 | 见设置页截图 |
| 不执行 VCS 操作 | 全程未 `stash / reset / checkout / commit` | — |

## 9. 最终推荐

**默认「轨道线」，保留「关闭」作为一键退路。**

理由：

1. **和现有「线构」同源**：圆、线、点、方形块、切角都是已有母题，不需要为背景再解释一套视觉语言；
2. **性能上限最高**：零 Canvas、零帧循环，输入延迟与滚动完全不受影响，符合「不为动效牺牲流畅」的底线；
3. **可扩展**：将来若想加强，只需在同一层里替换 `.bd-orbit` 的构图，不用动令牌与开关；
4. **星野与等高线作为「场景化替换」**：夜间切星野、想要纸张地图感切等高线；两者都已经过性能封顶与对比度控制，不存在「必须牺牲性能才能看」的档位，所以本次不需要你拍板做取舍。

如果一定要选一个「第二推荐」：深色模式下的**星野**——它是三套里唯一有「活着的背景」感觉的，且 30fps + 隐藏暂停已经把代价压到了可接受范围。

**推荐参数**（不动滑杆即可，这已经是各主题的出厂值）：轨道线 `50 / 92% / 0px / 92%`、星野 `50 / 92% / 0px / 94%`、等高线 `50 / 90% / 1px / 90%`。只有在「想要背景更轻」或「长时间专注」时，把强度降到 40–60% 或直接选「关闭」；模糊建议保持 0–1px，那是「发丝线」气质成立的位置。

**没有需要你拍板的取舍**：三套主题都在「不牺牲正文可读性、不引入新依赖、不阻塞首屏」的前提下落地，模糊这一唯一的观感取舍已经用线宽补偿解决（见第 3.1 节），因此不需要在「好看」与「流畅」之间二选一。
