# 个人信息管家 · v2.13.1 发布说明

**网页版（始终最新）**：https://personal-agent-08495.app.workbuddy.link/

打开即可用，无需安装；登录后数据在云端，换设备/浏览器仍在。

> 本版主题：**界面不再只有一种样子，你挑顺手的。**
> 三套界面方案随你切换，功能和数据一条都不动；不主动去设置里挑，就和你熟悉的旧界面完全一样。

---

## 本版新增：三套界面方案

到 **设置 → 界面方案**（或点顶栏那个调色板图标），三选一，点一下立刻生效：

### 一、静默化（出厂默认）

只收敛视觉，不改布局、不改交互。主色从十几种散落的用色收成一套、圆角从四五种收成一套、字号层级理顺。你原来点哪儿还是点哪儿——**只是看起来更安静、更统一**。

适合：已经用习惯了，不想界面动来动去。

### 二、分区骨架

把页面装进明确的骨架里，信息有主次：

- 内容区按页面类型分档变宽（表单 860 / 列表 1120 / 看板 1280），不再所有页面都挤在同一个窄条里
- 顶栏精简：从 7 个元素收到 2 个。「快速记录」下移到页头右侧（还是同一个落点），导出、退出收进头像菜单
- 首页改左右分栏：左边是记录卡片主区，右边一列三张统计卡，扫一眼就知道本周记了多少
- 卡片悬停轻轻抬起，能看出"这个能点"

适合：屏幕大、一次想看更多东西。

### 三、流畅优先

每次操作都给你即时回应：

- 动效分三档（进入 220ms / 退出 140ms / 位移 260ms），不再是所有动画一个速度
- 列表加载出**骨架屏**，不再是一个转圈等在那儿
- `Ctrl+K` **命令面板**：搜动作、切方案、跳页面，一个框全搞定
- 勾选待办**同帧划掉变灰**，后台失败会自动回滚
- 页面切换带过渡

适合：觉得现在"点了没反应"、"有点卡"。

## 怎么切、怎么退回

- **两个入口，位置永远不变**：顶栏调色板图标（切完**停在当前页**，当场就能看效果）+ 设置页「界面方案」卡片（列出改动要点、影响面、风险）
- **点选即生效，不弹确认框**——切换本身可逆，多一次确认只是多一次点击
- 切完底部有 **6 秒撤销条**，手滑了直接退回
- 提示会**点名代价**：从静默切分区会说"页面容器会变宽、首页改为左右分栏"，而不是含糊的"界面已更新"
- 方案只改呈现，**不碰任何数据**，随时回退，也可以点「恢复默认」

## 一个说明：偏好默认只在本机生效

界面方案记住的是**这台设备**的选择，换电脑/换浏览器会回到默认。设置页会如实显示同步状态。

想让它在所有设备跟随，需要执行一次数据库迁移 `docs/v2.13/migration-ui-scheme.sql`（只加一个可空列，可重复执行）。不执行也能正常用，不影响任何功能。

## 桌面端（Windows）

安装包：`个人信息管家 Setup 2.13.1.exe`（76 MB）

装它才有**系统托盘、桌面悬浮窗和原生系统通知**——网页版的通知只能在你开着浏览器时弹。Web 与桌面共用同一套云端数据，可以两边都装。

三套界面方案桌面端同样可用（桌面端窗口里就是网页版界面），切换后立即生效。
