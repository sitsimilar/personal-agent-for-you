> **本文件由 `web/src/lib/shortcuts.ts` 自动生成，请勿手改。**
> 重新生成：`npm run shortcuts:doc`；一致性校验：`npm run shortcuts:check`（`qa/shortcuts.test.ts` 也会比对）。
> `Ctrl / ⌘` 在 macOS 上为 `⌘`（运行时按 `ctrlKey || metaKey` 判定）。

| `?` | 查看快捷键速查 | 全局 | 否 | — |

## 约定

- 输入框、文本域、可编辑区域内只保留 `Ctrl / ⌘ + K`：打字优先，其余快捷键让位。
- 任一对话框打开时，全局快捷键整体挂起，只保留命令面板的开关。
- 快捷键只在登录后的壳层内注册；登录页不响应。
